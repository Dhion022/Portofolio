Tentang Saya

Halo! Saya Muh. Dhion. R, mahasiswa aktif program studi S1 Sistem Informasi di Universitas Sembilanbelas November Kolaka. Saya memiliki ketertarikan yang kuat dalam dunia teknologi informasi, khususnya di bidang pengembangan web dan analisis sistem.

Selama menempuh pendidikan, saya terus mengasah kemampuan dalam pemrograman, desain basis data, dan pengembangan antarmuka pengguna. Saya percaya bahwa teknologi adalah alat yang tepat untuk memecahkan masalah nyata dan menciptakan dampak positif.

Di luar akademik, saya aktif mengeksplorasi proyek-proyek mandiri untuk memperdalam pemahaman teknis saya. Tujuan saya adalah menjadi seorang profesional di bidang teknologi yang dapat berkontribusi secara nyata bagi masyarakat dan industri.

Proyek

Portofolio Web

Website Portofolio Pribadi

Website portofolio pribadi modern dan interaktif yang dibangun menggunakan HTML5 semantik, CSS3 modern, dan JavaScript murni. Menyajikan informasi profil, riwayat pendidikan, showcase keahlian teknis, animasi pengetikan dinamis, serta navigasi responsif yang nyaman diakses di ponsel maupun komputer.

HTML5 CSS3 JavaScript Responsif
Lihat Demo GitHub
Fitur Interaktif

Sistem Komentar & Buku Tamu Interaktif

Modul komentar interaktif client-side yang terintegrasi pada website portofolio. Pengunjung dapat mengirimkan nama dan komentar yang langsung ditampilkan secara real-time dan tersimpan secara persisten menggunakan LocalStorage, dilengkapi validasi formulir dinamis dan sanitasi pencegahan serangan XSS.

JavaScript LocalStorage DOM API Validasi Form
Coba Fitur GitHub
Sistem UI/UX

Sistem Desain & Tema Dark / Light Mode

Arsitektur tema ganda dinamis (Dark & Light Mode) dengan transisi visual halus menggunakan CSS Custom Properties (Design Tokens). Mendukung deteksi preferensi sistem pengguna, penyimpanan status tema di LocalStorage tanpa efek layar berkedip (anti-FOUC), dan skema kontras warna yang nyaman untuk mata.

CSS Variables Design Tokens JavaScript Aksesibilitas
